1. Train & Export the Model
Creates a dummy mini-LLM and exports the TF SavedModel.

Bash
python src/train.py
2. Convert & Quantize to TFLite
Converts the SavedModel to an INT8 quantized TFLite model.

Bash
python src/convert.py
3. Run Edge Inference
Simulates on-device inference using the optimized TFLite model.

Bash
python src/infer.py
